# ClimaAgora - Vite + React

Aplicação para consultar o clima atual e a previsão dos próximos 6 dias por cidade.

## Tecnologias
- Vite
- React
- Lucide React
- API Open-Meteo (gratuita, sem chave)

## Como executar

1. Abra a pasta `frontend` no VS Code.
2. Execute `npm install`.
3. Execute `npm run dev`.
4. Acesse o endereço informado pelo Vite (normalmente http://localhost:5173).

A consulta usa a API de geocodificação e previsão da Open-Meteo, portanto é necessária conexão com a internet.
